# JobHunter

Поиск вакансий в Испании (LinkedIn, Jooble, InfoJobs, Job Today) с четырьмя ИИ-агентами.

## Запуск
Двойной клик по `run.bat` → откроется браузер (http://localhost:8501).

## Агенты
| # | Агент | Что делает | По умолчанию |
|---|---|---|---|
| 1 | Анализ резюме | профиль, сильные/слабые стороны, советы, ключевые слова для поиска | Claude |
| 2 | Анализ вакансий | % совпадения, требования, чего не хватает, red flags | Ollama (qwen2.5:14b) |
| 3 | Сопроводительное письмо | carta de presentación на испанском под вакансию | Claude |
| 4 | Адаптация резюме | новый «Perfil», ключевые слова, правки под вакансию | Claude |
| 5 | ATS-аудит | по найденным вакансиям: ключевые слова и синонимы, стоп-критерии, что HR смотрит первым | Claude |
| 6 | Новое резюме | переписывает резюме под ATS (только реальные факты) → PDF и DOCX | Claude |

### Как работает улучшение резюме (вкладка «Резюме»)
1. Проверки в коде, без ИИ: читается ли файл роботом, есть ли email и телефон, стандартные ли заголовки,
   нет ли таблиц, колонтитулов, иконок и колонок.
2. Агент 5 строит список ключевых слов по вашим вакансиям; в коде считается, какие из них уже есть в резюме (% покрытия).
3. Агент 6 переписывает резюме. Код дополнительно убирает выдуманное (например, разрешение на работу, которого нет в исходнике).
4. Готовый PDF проверяется так же, как его прочтёт ATS: текст извлекается обратно, и покрытие считается заново.

Язык нового резюме по умолчанию совпадает с языком исходного (es/en/ru); его можно выбрать вручную.
Скрытый текст и списки слов ради слов не используются: ATS и HR это ловят, а навыки, которых нет, вскроются на собеседовании.

Бэкенд каждого агента переключается во вкладке «Настройки».

## Автопилот (вкладка «🤖 Автопилот», код: `jobhunter/pipeline.py`)
Запускается по расписанию (Планировщик Windows, задача «JobHunter Autopilot», по умолчанию 09:00 и 15:00):
1. Поиск по списку запросов во всех источниках, без дублей.
2. Фильтры в коде, без ИИ: обязательный английский B2+/C1/fluent («valorable» не считается), вакансия на английском,
   только удалёнка (если включено), стоп-слова. Отсеянное видно во вкладке, его можно вернуть.
3. Оценка новых вакансий агентом 2 (Ollama; если она не запущена, автопилот запускает её сам).
4. Для лучших (совпадение ≥ порога, не больше N за запуск): резюме под вакансию (агент 6) + письмо (агент 3).
   Файлы: `data/applications/<дата-компания-вакансия>/` (PDF, carta.txt, vacante.txt), статус «📦 Готово к отправке».

Автопилот ничего не отправляет сам. Вручную: `.venv\Scripts\python.exe -m jobhunter.pipeline [--skip-search] [--max-prepare N]`,
расписание: `--install-schedule` / `--remove-schedule`. Журнал: `data/pipeline.log`.

## База фактов и треки (вкладка «🧾 База фактов», код: `jobhunter/facts.py`)
Эталон — честный подробный рассказ о себе (по-русски). Резюме, письма и оценка вакансий строятся по нему,
а не по старому резюме. Пункты с пометкой «УТОЧНИТЬ» агенты не используют, а задают по ним вопросы:
они приходят в Telegram (ответ — реплаем) и видны во вкладке. Ответы становятся частью базы.
Треки: «поддержка» (основной) и «фронтенд»; трек вакансии определяется по её названию.
Мастер-резюме треков: `data/master/`, пересборка — кнопкой во вкладке или командой /cv.

## Telegram-бот (`jobhunter/telegram_bot.py`)
После каждого прогона автопилот присылает новые готовые отклики: карточку вакансии, PDF резюме и письмо
с кнопками «✅ Отправил», «🙈 Пропустить», «✏️ Поправить письмо» (пишешь пожелание — агент 3 переписывает).
Команды: /ready, /status, /run. Бот привязывается к первому чату, написавшему /start, остальные игнорирует.
Токен — `TELEGRAM_BOT_TOKEN` в `.env`. Слушатель кнопок стартует при входе в Windows
(`Автозагрузка\JobHunter Telegram.vbs`), журнал — `data/telegram.log`.

## Источники
| Источник | Как работает | Нужно |
|---|---|---|
| LinkedIn | публичная гостевая выдача, без логина, с паузами | ничего |
| Job Today | публичные страницы jobtoday.com/es | ничего |
| Jooble | официальный API (только краткое описание вакансии) | ключ: https://jooble.org/api/about |
| InfoJobs | официальный API | client_id/secret: https://developer.infojobs.net |

LinkedIn и Job Today не имеют API — это парсинг страниц, он может сломаться при изменении сайта
или временно блокироваться (429). Остальные источники при этом продолжают работать.
Вакансию с любого сайта можно добавить вручную (ссылкой или текстом) во вкладке «Поиск».

## Ключи
Вводятся во вкладке «Настройки» и хранятся только в `D:\JobHunter\.env`.
Без `ANTHROPIC_API_KEY` переключите агентов 1, 3, 4 на `ollama`.

## Данные
`data/jobs.db` — вакансии, анализы, письма, резюме (SQLite). `data/settings.json` — настройки.
